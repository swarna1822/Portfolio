# Swarna Kumar Koppala — Portfolio

Keyboard-inspired React portfolio for a frontend engineer resume.

## Run locally

```bash
npm install
npm run dev
```

Open the printed local URL (usually `http://localhost:5173`).

## Notes

- LinkedIn is set from a public profile match.
- GitHub currently points at `https://github.com/swarnakumark48` based on the resume email. Update `src/data/resume.js` if your username is different.
